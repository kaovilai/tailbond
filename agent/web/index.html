Add a GL.iNet travel router (recommended)

  1. Download the router package to this computer.Get the router package (the file ending in _neon-vfpv4.ipk) from whoever set up tailbond.
  2. On the travel router's admin page: SYSTEM → Advanced Settings → Go To LuCI, then System → Software → Upload Package…, pick the file, Install.
  3. Back in the router's admin page, open VPN → tailbond and tap Ask to connect. Approve it here when it shows up at the top.

Add a device with a code (no Tailscale on it)

Routers and phones on your Tailscale account don't need this: they ask to connect and show up at the top of this page. For others: each gets its own key. In the tailbond app tap Scan code from your home server, or paste the link on the router's tailbond page (Other ways to connect). On the phone itself, open this page and use Add this phone.

Invite someone's phone

Send this link to a family member. They open it on their phone while Tailscale is on, and tap Add this phone.

Pair with your home server

On the server's dashboard open Clients → Add, then paste the tailbond://pair link here or scan its QR code.
