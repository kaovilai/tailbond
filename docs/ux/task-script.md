# Simulated user test: task script

You are trying out **tailbond**, an Android app. Context you were given by the
person who set it up: "tailbond bonds your phone's Wi-Fi and 5G together to our
home server. The home server is on our Tailscale network, so with tailbond on
you still reach all the Tailscale machines (like the NAS). Android only allows
one VPN app at a time, so you use tailbond instead of the Tailscale app."

Today the phone only has the official Tailscale app installed and working.

Tasks:
1. Install tailbond and pair it with the home server, from the phone.
2. Connect.
3. Find and copy the NAS's MagicDNS name or Tailscale IP (the NAS is called `nas`).
4. Tell whether Wi-Fi and 5G are both being used right now.
5. Make it save cellular data.
6. Turn tailbond off and go back to the Tailscale app.

For each task report:
- where you would tap (refer to the screenshot file and the on-screen text);
- where you would get stuck or misunderstand something (quote the exact on-screen text);
- what you expected instead, based on how the official Tailscale Android app behaves;
- severity: high (can't finish the task / would do something wrong), medium
  (finishes with real confusion or extra effort), low (polish).

You only have the screenshots. A screen that doesn't exist means the task
can't be done that way; say so. Don't invent features that aren't shown.
